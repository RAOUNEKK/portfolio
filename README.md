## Project description

A personal portfolio website that presents who I am, the projects I have built, my skills, and a way to contact me. It is a responsive, multi-page site: Home, About, Projects (with a detail page for each project), Skills and Contact. The projects showcased include CyberLens, SWAP, Foliora, Piczzly, NutriAI and LP Solver.

## Technologies used

- **JavaScript (ES modules)** and **React 19**
- **TanStack Start** and **TanStack Router** (file-based routing, server-side rendering)
- **Vite** (build tool) and **Nitro** (server output)
- **Tailwind CSS 4** and **shadcn/ui** (Radix UI) for styling and components
- **Lucide React** for icons
- **Resend** (server-side API route) for the contact form
- **ESLint** and **Prettier** for code quality
- **Git / GitHub** for version control and **Vercel** for deployment

## Implemented features

- Responsive design that works on mobile, tablet and desktop
- Multi-page navigation: Home, About, Projects, Skills, Contact
- Projects list and a dedicated detail page for each project
- Skills page grouped by category (programming languages, tools, etc.)
- Light / dark theme toggle, remembered between visits
- Contact form that sends messages by email through a server-side API route
- Interactive visual elements (welcome collage, lanyard badge, portfolio board)
- Custom error page and 404 handling
- Deployed online on Vercel

## Run locally

```bash
npm install
npm run dev      # development server
npm run build    # production build
```
